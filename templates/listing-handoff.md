# Listing handoff

## Status

State: proposed copy / incomplete draft / ready for seller review / MakeBox-only saved / Etsy accepted but unverified / Etsy draft verified / Etsy active verified.
Source and capture time; exact target/shop if connected. No write implied by a draft.

## Copy-ready fields

TITLE — complete plain-text field, character count outside it.

DESCRIPTION — complete revised plain text, all factual sections preserved.

TAGS — one phrase per line or a comma-separated list, count and per-tag lengths in the review notes.

MATERIALS — confirmed components only.

PERSONALIZATION — exact question/instructions; type, required and limit separate.

ALT TEXT — one entry per real image.

## Settings worksheet

Category path/verified ID; applicable attributes; maker/date/supply/partners; price/currency/quantity; full variant table/SKU/stock; section; delivery/processing; confirmed packed units; returns; digital files/access/license. Use `not applicable` or `not confirmed` explicitly.

## Review

What changed and why; evidence for primary keywords; factual/operational blockers; before/after only for edited fields. A ready-to-paste field contains no editorial notes/placeholders.

## Next action

Standalone: named Etsy fields to paste, settings to select, Save as Draft, inspect full preview. Publication is the seller's separate decision.

Connected: exact tool/arguments and affected resource for any needed authorization; then per-step readback results and unresolved details. In a batch, report each listing separately; never call partial completion total success.
