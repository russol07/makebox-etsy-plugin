# MakeBox for Etsy — версія 0.3.0

Плагін працює у двох режимах. Без MCP він готує повний лістинг із наданих фото, фактів, тексту або CSV: заголовок, повний опис, теги та таблицю налаштувань для ручного перенесення в Etsy. З MCP — читає свіжі дані й виконує конкретно дозволені зміни з перевіркою результату.

Роль агента: досвідчений Etsy SEO-стратег, товарний маркетолог і редактор текстів, який також розуміє варіації, персоналізацію, доставку, пакування, політики, медіа та замовлення. Для клієнтів без підтримки окремих агентів ця сама роль доступна через координаційний скіл.

Додано практичні посібники, шаблони та приклади. Агент відрізняє підтверджені факти від припущень, не вгадує матеріали й розміри посилки, не вигадує статистику пошуку. Довгий опис він структурує і повертає повністю зі збереженими характеристиками та умовами. Окремі правила є для цифрових файлів, фото, відео, повернень, варіацій і всіх питань персоналізації.

Довідник містить назви та схеми 105 прямих методів, звірені з кодом MakeBox. Жива схема інструмента має пріоритет. Є локальні перевірки структури, лімітів, дублів тегів та прикладів API; вони не виконують клієнтські дії, не витрачають кредити й не підтверджують якість SEO автоматично.

Пакети `connected` включають декларацію MCP. Пакети `standalone` мають порожню конфігурацію MCP і ту саму базу знань. Встановлення конектора Muse саме собою не встановлює скіли чи агента; це залежить від можливостей конкретного клієнта.

Підготовка пакета не означає схвалення чи публікацію в каталогах. Англомовні матеріали призначені для користувачів плагіна; цей файл пояснює їхній зміст українською.
