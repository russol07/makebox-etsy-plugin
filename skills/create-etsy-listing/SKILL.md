# Create a complete Etsy listing

## Intake and positioning

Read [product brief](../../references/product-brief.md) and [quality playbook](../../references/listing-quality-playbook.md). Establish exact item/count, physical or digital, construction/size, main use, options and included parts. Collect maker, real price/stock/currency and fulfillment facts for a complete settings packet. Record confirmed/observed/missing/conflicting facts. Ask only meaningful missing questions and draft independent content now.

Choose a primary buyer intent using [research](../../references/keyword-research.md) where evidence is available. No metrics is not a reason to invent them. Never write competitor-owned brands, designs or unsupported material/holiday claims into the listing.

## Compose the whole packet

1. Readable item-first title within 140 characters; shortness is guidance, not compulsory 140-character padding.
2. Full plain-text description: offer/contents, details, options/order instructions, delivery/access, applicable care/limitations. Long descriptions retain every essential fact.
3. Complete new SEO set: thirteen unique relevant phrases, each ≤20 characters, normally multi-word in space-delimited languages. If a real relevance gap remains, label it rather than fill with junk. Native direct transport can retain fewer approved tags.
4. Most specific accurate category and applicable attributes/materials/occasion. IDs only from current taxonomy.
5. [Complete variants and personalization](../../references/variations-personalization.md); real prices/stock/SKUs, question limits/examples and proof process only if offered.
6. [Physical delivery/packaging/returns](../../references/shipping-packaging.md) OR actual digital contents/access/license; [media plan](../../references/media-digital.md).

## Standalone delivery

Use [handoff](../../templates/listing-handoff.md) with exact pasteable fields, settings table, blockers and Save as Draft/manual preview steps. See [worked examples](../../references/worked-examples.md). Do not require MCP or claim configuration happened. Unknown values belong outside ready-to-paste text.

## Connected completion

Read [creation route](../../references/listing-creation-guide.md) and [operation recipes](../../references/etsy-operation-recipes.md). Identify target shop; validate current schemas and real taxonomy/profile IDs. Show the actual draft and obtain/reuse exact authorization. Send `etsy_create_draft_listing` once, read the new listing, then complete approved inventory/personalization/media. Do not invoke internal AI merely to transmit copy. Activate only when publication is authorized and prerequisite facts/media are complete; read actual state. A timeout/partial upload is not permission to create another listing.

Finish with [release checklist](../../checklists/listing-release.md); optional local QA checks limits, not truth or rank.
