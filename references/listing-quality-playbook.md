# Listing quality playbook

Use with the fact ledger. These editorial standards are not Etsy's ranking formula. Native constraints and optional writing guidance are distinct.

## Offer and intent

Form an internal sentence: `This is [item/count] for [main use], distinguished by [confirmed trait], with [ordering choice].` Thumbnail, title, price and description must communicate the same offer. Separate digital templates from printed goods. Choose a coherent buyer intent rather than every possible gift audience.

Translate confirmed features into useful consequences: a supplied stand permits desk display; editable text permits name changes in the stated software. Avoid invented best-seller status, false scarcity, reviews, safety claims and unsupported sustainability or longevity. Use original copy and the seller's voice.

## Title

Native maximum 140 characters. Lead with the item and distinguishing factual traits. A readable title under 15 words is guidance, not a rejection rule. Occasion/recipient belongs when integral to the item. Avoid repeated synonyms, price/shipping promotions and unsupported superlatives.

The current API title rule allows letters, digits, punctuation, mathematical symbols, spaces and ™/©/®; each of `%`, `:`, `&`, `+` may appear only once. Avoid decorative emoji/control characters in executable titles. Read current requirements rather than assuming every Unicode symbol is valid.

Original example: `Personalized Acrylic Desk Sign, Custom Name, 8 × 3 Inches`. Material, size and customization must be confirmed. Digital example: `Editable Wedding Seating Chart, Minimalist 24 × 36 Inch Template` only if the size/editing capability exists. Do not fill the character budget unnecessarily. Front placement aids scanning, not guaranteed rank.

Deliver one recommended title; offer two alternatives only if they express different viable positioning. Keep explanations outside copy-ready fields.

## Description architecture

Use plain text, short paragraphs, descriptive headings and lists where useful. No universal word quota. Length follows the product's buying questions.

| Module | Include when applicable |
| --- | --- |
| Opening | Item, confirmed differentiator, main use; natural buyer language |
| What you receive | Exact count, components/accessories/files, exclusions |
| Details | Size/units, materials, finish, technique, verified compatibility |
| Choose your options | Choices and how they affect item/price |
| Personalization / How to order | Input example, limits, spelling/case, actual proof process |
| Delivery / Access | Physical processing/transit distinction OR actual digital access |
| Care / Installation | Verified instructions and mounting requirements |
| Important notes | Relevant limitations, tolerances, license and policy |

Not every item needs every heading. A buyer should understand what arrives, whether it fits, how to choose it and how it is delivered. Keywords belong naturally in meaningful prose, not a repeated title or keyword block. Keep critical specifications prominent.

**Long descriptions:** inventory every factual section before editing. Preserve specifications, ordering steps, valid disclosures and fulfillment terms. Remove repetitive claims and improve structure. The review summary may be short, but deliver the **full revised description**, never an excerpt that loses important facts. If the host output limit prevents this, save a full text file when supported or return explicitly numbered parts. Do not silently truncate.

## Tags

Native field: up to 13 tags, each at most 20 characters. Newly generated complete sets should have 13 distinct relevant phrases, normally multi-word in space-delimited languages. MakeBox internal generation enforces exact-13 multi-word output; direct seller-approved transport follows native Etsy rules. If evidence cannot support thirteen, explain what is missing rather than add filler or pretend ten is thirteen.

Build candidates around identity, construction, style, customization, use/problem and truly relevant audience/occasion. Every phrase should add coverage. Repeated product nouns can be legitimate; near-identical phrases rarely help. Use supported category/attribute information and avoid redundant exact phrases where stronger alternatives exist. Avoid deliberate typos, plural-only duplicates, unrelated holidays and unauthorized brands/characters. Use the shop language; never insert artificial spaces in non-space-delimited languages.

For each tag: does it fit this exact item, would that buyer be satisfied, is it useful and distinct, does it fit without awkward abbreviation? Metrics only compare relevant choices. Never select wrong materials because demand is high.

## Complete the settings

- Accurate specific category; taxonomy IDs come from current tools, not guesses.
- Supported truthful attributes, real material components, product dimensions distinct from package dimensions.
- Occasion/holiday only when accurate; gifting prose cannot create a dispatch guarantee.
- Sellable option combinations with price, stock, SKU and enabled state; [options guide](variations-personalization.md).
- Correct delivery/processing/returns; [shipping guide](shipping-packaging.md).
- Exact product media and actual download files; [media guide](media-digital.md).
- Truthful maker, date/supply status and relevant production partners; do not hide outsourcing or invent vintage provenance.

## Quality review and measurement

Use `pass / needs work / unknown` for accuracy, buyer clarity, keyword fit, offer consistency, operational completeness and field validity. This is an editorial checklist, not an Etsy score or probability.

Record baseline period, source and available views/visits, favorites, orders, revenue/search terms. Distinguish shop from listing metrics. Calculate conversion only from compatible orders/visits over the same period, with sample size shown. Low traffic suggests a discovery/photo/title hypothesis; traffic without orders suggests an offer, delivery, pricing or trust hypothesis. One number cannot establish the cause. Hold unrelated settings constant and agree an evaluation window; avoid repeated rewrites before evidence accumulates.
